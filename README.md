# Comic Explorer for Android

端末に保存した漫画やPDFを読む、Android向けのローカル漫画ビューワです。画像をまとめたZIP / CBZや画像フォルダを開き、続きのページ、しおり、お気に入りを端末内に保存できます。

広告・課金はありません。ローカル閲覧にアカウントは不要です。SMB／FTP／FTPSの接続機能と、Google Driveを使う任意のページ再開同期を追加しています。

## 対応環境と形式

Android 10（API 29）以降に対応しています。

| 形式 | 読み方・制限 |
| --- | --- |
| PDF | ページ閲覧、目次からの章ジャンプ、パスワード付きPDFに対応 |
| ZIP / CBZ | アーカイブ内の画像を閲覧。ファイル名の文字コードはUTF-8 / Shift_JISなど7種類から選択可能 |
| RAR / CBR | RAR4/5、分割・暗号化アーカイブの画像を閲覧 |
| 7z / CB7 | 画像アーカイブを閲覧。展開メモリ上限64 MiB、画像1枚48 MiBまで |
| 画像・画像フォルダ | JPG / JPEG、PNG、GIF、BMP、WebPに対応。フォルダ内の画像を続けて閲覧可能 |
| AVIF | 端末のAndroid画像デコーダーが対応する場合に表示 |

GIFは最大約30fpsで再生し、切り抜き・フィルター・見開きにも対応します。AVIFの対応はOSと端末に依存し、特にAndroid 10 / 11では表示を保証しません。

暗号化した作品は、開いたときにパスワードを入力します。パスワードは保存しません。分割アーカイブは最初のファイル（例：`.part1.rar`、`.7z.001`）を開き、不足するファイルを選択して追加してください。

## インストール

1. Android端末で [Releases](https://github.com/s-deme/comic_explorer_portable/releases/latest) を開き、APKをダウンロードします。
2. ダウンロードしたAPKを開き、Androidの案内に従ってインストールします。
3. アプリ一覧から「Comic Explorer」を起動します。

このリポジトリはAndroid版です。Windowsデスクトップ版の `comic_explorer` とは、配布物、対応形式、保存方式が異なります。

## 最初の操作

1. 「フォルダを選ぶ」を押し、Androidのフォルダ選択画面で漫画の入ったフォルダへのアクセスを許可します。
2. 一覧からPDFやZIP / CBZをタップして開きます。画像フォルダは中へ移動して画像をタップすると、同じ一覧の画像を続けて読めます。
3. スワイプまたはページボタンで移動し、画像上をタップして読書メニューを表示します。ページ番号やスライダーからも移動できます。
4. 右上の「⋮」から、しおり・自動ページ送りなどの読書メニューを開けます。自動送り中は同じ場所から停止できます。スクロール方式・画面への合わせ方・画面回転・ページボタン・ハードウェアキーは中間メニューを挟まず直接開けます。メモ編集は「しおり」にまとめています。
5. 読書ツールバーは1段で、ページ一覧・ページ送り方向・ページレイアウト・画像フィルターを直接操作できます。ページ一覧は画面中央に表示され、サムネイルをタップして移動します。次回は「履歴」や「しおり」から作品を探せます。

作品の長押しでお気に入りに追加できます。よく使うフォルダは長押しして「ディレクトリに登録」すると、「ディレクトリ」タブから開けます。ほかのアプリの「開く」から対応ファイルを渡すこともできます。

## 主な機能

- **作品を探す**：ストレージ／ディレクトリ／履歴／しおりタブ、お気に入り、検索、並べ替え、アイコン／サムネイル／1〜10列グリッド。ファイル名・背景色・正方形サムネイルも設定できます。
- **続きを読む**：ページ位置の保存、最大100件の読書履歴、履歴の期間指定消去、しおり一覧とメモ。
- **ページを送る**：初期設定は漫画向けの左送り（右から左へ読む順序）。変更済みの送り方向は保持します。単ページ／見開き／横画面で自動見開き／強制単ページ、縦連続スクロール、左右の読書方向、自動送り、ハードウェアキー割り当て、次の作品へ移動。再開方法は通常と次の作品で個別に設定できます。
- **見開き画像を片側ずつ読む**：「ページレイアウト」→「強制単ページ」を選びます。横長画像だけを中央で左右に分割し、左送りでは右半分→左半分、右送りでは左半分→右半分の順に表示します。横画面・縦スクロールでも有効です。書庫や画像は変更せず、しおりは元画像単位で保持します。
- **拡大して読む**：ピンチ操作、ダブルタップ、画面・幅・高さに合わせる表示と画面いっぱいへの伸縮。
- **表示を調整する**：色反転、グレースケール、画素に基づく自動コントラスト、拡大補間、シャープ、ブルーライト軽減を組み合わせて設定。ページ間隔も調整できます。ページボタンは画面サンプルを見ながら配置を直接選び、位置・サイズ・不透明度を調整できます。
- **テーマを選ぶ**：設定の「テーマ」からライト・ダーク・赤・青・緑・紫・ピンク・オレンジ・グレーを色見本付きで選択し、即時反映。「システムに合わせる」も利用できます。色付きテーマは暗い背景を基本とし、漫画の画像には着色しません。個別に指定したグリッド背景色は保持します。
- **設定と管理**：言語、キャッシュ容量・保持日数・種類別消去、位置／しおり／履歴の個別消去、中央表示のページ一覧、章一覧、色パレット、ギャラリーとアルバム。アプリ設定は書庫選択画面から開きます。
- **ファイル操作**：複数選択、コピー／移動、連番への名前変更、削除。フォルダ全体や別保存先への転送に対応し、同名項目は両方保存／置換／スキップを選べます。移動時はコピーを検証してから元データを削除し、フォルダ内の読書位置・しおりも引き継ぎます。
- **アルバム**：「操作 → アルバム」で作成し、画像を追加できます。アルバムは元画像への参照を保存し、アルバム削除や登録解除で元画像は消しません。

## 利用上の制限

- 読み取り対象は、Androidの選択画面で許可したフォルダ・ファイル、または外部アプリから渡されたファイルです。アクセス許可が失われた場合はフォルダを選び直してください。
- ソリッド圧縮はページ移動時に前のデータも展開するため、大きな作品では時間がかかります。すべての圧縮・暗号方式の組み合わせを検証したものではありません。
- ファイル操作には保存先側の対応が必要です。コピーは一時領域を使用し、移動は削除前に構成・内容を再照合します。転送中は別アプリで元ファイルを編集しないでください。1回のフォルダ転送は20,000項目・深さ64までです。
- 名前変更・移動・削除には保存先の書き込み権限と操作対応が必要です。削除は元ファイルに反映されます。履歴やお気に入りの解除は作品ファイルを削除しません。
- Google Drive同期にはアプリのOAuth登録が必要です。この作業環境では認証・端末間同期を未検証です。SMB／FTPSの実サーバー接続も未検証です。
- 日本語・英語・韓国語・ロシア語のUIを収録しています。補間方式名などの技術用語は共通表記です。
- ギャラリー利用時のみ画像の読み取り権限を要求します。ネットワーク接続・同期には通信権限を使います。同期するのは作品のハッシュと復帰位置で、作品ファイルはアップロードしません。

ビルド、署名、CI、リリース、検証範囲については [開発者向け手順](DEVELOPMENT.md) を参照してください。
